# PDF360

An open-source, highly modular, and extensible desktop PDF platform.

## Description

PDF360 is a next-generation desktop PDF application built with modern technologies for performance, flexibility, and extensibility.

## Tech Stack

- **Backend**: Rust with Tauri v2
- **Frontend**: React with TypeScript
- **PDF Engine**: MuPDF

## Status

⚠️ **Early Development** — This project is currently in early development. Features are incomplete and APIs may change.
